# Vask Media Player

Portable Windows player for local video files. No install.

Unzip this folder and run Vask.exe. Keep the engine folder and idle.webm next to it.

Playback is handled by the bundled mpv build in engine. Those programs are not written by Vask and stay under their own licenses. See licenses/licenses.txt. mpv and FFmpeg source is available from the links in that file.

This download does not include the Vask interface source.
