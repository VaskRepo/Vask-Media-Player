# Vask Media Player

Portable Windows player for local video files. No install and no account.

## Download

Get the latest zip from [v0.9.309](https://github.com/VaskRepo/Vask-Media-Player/releases/tag/v0.9.309). Unzip the folder and run Vask.exe. Keep the engine folder and idle.webm next to it. You can move the whole folder. Settings stay in that folder.

## Play a file

Open opens one video. Open files opens several, and they play in order. You can also drop a file on the window.

<img width="1626" height="1032" alt="image" src="https://github.com/user-attachments/assets/660f6c9b-f5eb-4c0c-8c3a-076414cbdac0" />

The controls sit at the bottom and hide until you move the mouse there. Pause, stop, previous, next, seek, volume, and mute are on that bar. The folder icon on the left opens the library. The icon on the right is fullscreen. Double-click the video to enter or leave fullscreen.

<img width="1624" height="1044" alt="image" src="https://github.com/user-attachments/assets/7e7e39b2-65e3-492b-9ff3-381c5be1940a" />

## Library

The library stores folders, not copies of the videos. Add a folder, open it, and play a file from the list. Drag the edge to resize it. Drag names to reorder them in the same folder. Right-click a folder or file for a color, or to open its location.

<img width="1626" height="1035" alt="image" src="https://github.com/user-attachments/assets/409cb7bf-99c3-4aad-9133-7f8ce68aa162" />


## Bookmarks

While a video is playing, right-click and choose Save to keep the current time. Load jumps back to a saved point for that file. The Bookmarks menu lists saved points and can open the video they belong to.

<img width="1617" height="1029" alt="image" src="https://github.com/user-attachments/assets/2cad5861-6237-4dcf-a93f-eaf0154fdb28" />

## Subtitles

Playback, Subtitles opens the editor. Set a start and end, type the line, and add it. The list stays sorted by time. A red time means two lines overlap. Click a time to jump there. Save writes an SRT into the SRT folder next to Vask. The video file is not changed. Link attaches an SRT you already have.

<img width="2711" height="1034" alt="image" src="https://github.com/user-attachments/assets/3a99842c-36ca-4818-a08b-b57f9b891b33" />

## Settings

File, Settings. Changes save as you make them.

General remembers the last file, the playback position, a single window, hardware decode, and always on top. Video covers the name shown on load, double-click fullscreen, aspect ratio, the idle logo, and how long the controls stay visible. Audio covers loudness and the output device. Hotkeys can be changed from the Hotkeys page. Click a key box, press the new key, and Escape resets that one.
